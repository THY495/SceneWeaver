# 可编辑示例故事

- [`ferry.story.json`](ferry.story.json)：《末班渡船》，六个场景、三名 NPC、物品和演示立绘。
- [`archive.story.json`](archive.story.json)：《雨夜档案馆》，两个场景、三名 NPC 和知情边界。

在 Sceneweaver Studio 的项目管理器中选择“导入可编辑故事包”，选取其中一个 JSON 文件。它们是合成测试故事，不含模型 API Key 或真实玩家记录。使用这些故事进行生成对话时仍需玩家或本机自行配置模型凭据；语音可选。
