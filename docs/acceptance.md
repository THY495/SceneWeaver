# Alpha 验收范围

`v0.1.0-alpha.1` 是源码预览，不是已经通过可信签名的 Windows 安装包。Sceneweaver Studio 与独立玩家游戏分离；仓库发布创作工具、运行源码和两部合成示例。运行独立 Windows 游戏的第三方/未签名运行库不随源码分发。

2026-09-30 本机验收：Studio UI 导入、保存、构建渡船与档案馆故事；独立游戏 Web 使用官方 DeepSeek 与可选阿里云新加坡 TTS 有真实播放样本。渡船六节点的两条手动路径分别从开场经不同场景与汇合节点到两个结局。另将开场两条出口在验收夹具中改为互斥 AI 条件，经 Studio 构建后在独立游戏 Web 中用真实模型走通两条分支。路由审计引用本轮玩家发言；两局读至结局，无浏览器脚本错误。修复后原工作区后端全量测试 663 项通过。发布目录只包含角色扮演相关测试及必要共享运行时测试，独立运行结果为 **576 passed**；Studio 与玩家 Web 均可构建，前端测试通过。另修复 Docker 非默认宿主机端口映射时的同源静态资源 403，并加入回归测试。

保留的失败：天气路径曾连续生成无证据的现场天气断言，两次都被审查拒绝，任务未转场。现为同一片段增加一次有上限的定向修复，每份候选仍须通过校验和审查。要求 NPC 带路但故事未定义公告栏具体位置时，NPC 会追问、转场等待玩家答复；玩家明确自行前往可正常进入对应场景。一次复跑的天气分支回合耗时 43.73 秒，说明多 NPC 串行演出与审查重试仍需优化。

未验收：本轮两条分支整局未开启 TTS；未在冻结 Windows EXE 中重跑；示例六节点复用同一背景，不能证明差异化场景美术体验；最新版陌生创作者从空工程独立试用尚未进行。源工作区的详细本机报告存于忽略目录 `.runtime/alpha/`，未包含在公开仓库中。
