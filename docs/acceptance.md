# 验证范围与已知限制

Sceneweaver 当前为 Windows 优先的源码 alpha 版本，提供故事创作工具、角色世界运行时和独立玩家 Web 界面。

## 当前能力

- 编辑故事 DAG、场景背景与人物构图、角色经历与关系、知情范围、造型、固定开场和导演演出段落。
- 配置可操作物品和容器，由运行时核验物品操作与剧情硬条件。
- 区分世界事实、人物言论和各角色实际观察，保留个人记忆与执行诊断。
- 配置 AI 条件出口，在玩家交互满足条件后推进到新的场景。
- 玩家使用自己的 LLM API Key；语音可选，需要独立的 TTS API Key。

## 已验证的范围

两部合成故事已用于故事导入、编辑、构建和本地试玩。渡船故事验证过两条手动分支、汇合节点和两个结局；另用派生测试故事与真实模型验证过两个互斥 AI 出口。工程保存重开、服务重启后的对白与进度恢复、真实 NPC 回答和短句 TTS 播放均有有限验证。

此前冻结源码候选完成过四输入固定短局：真实模型下，两名 NPC 围绕玩家请求互相回应，两条 AI 出口分别到达后续场景，再经手动选择到达两个结局；实际宿主重启后，同存档未读对白和阅读位置保持，13 段正式对白在独立游戏界面实际阅读。仍出现审核恢复长尾与重复表达，这不是长期质量或稳定响应速度验收；后续修订需要按变更范围重新验证。

同一此前候选的两个独立窗口验证了拖动物品提出交接、NPC 接受后的实际转移与同存档重载，以及真实模型请求在途时暂停、迟到响应不发表、继续新输入。物品第一次提议和接受保持所有权，第二次拖动才实际转移；本次没有覆盖 NPC 拒收。它们是有限固定窗口，不代表任意人物决定或剧情都能成功，也不是同一整局同时覆盖所有功能。

另用有限模型替身通过真实 Worker 和独立游戏界面验证了故障恢复：连续审核拒绝使当前任务失败，拒稿不发表，世界事实与物品保持，玩家收到错误提示后能继续发言，新回复正常显示。替身测试不评价真实模型质量或响应速度。

当前候选另验证了本地引用校验在进入语义审核前耗尽：两次错误引用均未发表，实际游戏显示可继续发言的提示；同一存档新输入产生正常审核后的新回复并实际阅读。检查覆盖世界设定、确认事件、角色场景事实以及物品内容和修订号不变；固定模型替身只证明这一恢复窗口，不证明真实模型能避免错误引用。

后续离线验证覆盖了已发表安全前缀后停止当前表演、保留前缀并继续新输入，以及返回主菜单时先停止本机播音、等待服务确认后导航。另修复了一类自动记忆整理只能完成首批的阻塞；受控历史和缩小容量下，正常前后台 Worker 能继续整理必要前缀。该检查不能代替默认容量下的真实模型自然长对话验收。

全新源码副本、无密钥示例配置及全新 Docker 数据卷实际构建启动成功；通过界面保存草稿，重开后故事背景和角色设定保留，缺少 LLM Key 时预览禁用。该检查使用已有 Docker Desktop 和构建缓存，尚不是干净机器安装或完整作品创作、分发验收。

另有一次固定十二轮真实模型轨迹完成，覆盖整理结果待安装时继续回应、部分听闻、来源删除、纠正与撤回；使用注入的合成历史和受控安装屏障，不等同自然长对话。部分正式回复仍有历史概括不精确和重复表达。

上述结果不代表所有故事、AI 出口、多 NPC 交流或长对话记忆都稳定可用，也不是原生 Windows EXE 或整局语音验收。每次检查绑定其冻结源码，后续修订不能直接继承旧结果。默认自动检查不调用付费模型；在安装开发依赖并启动测试数据库后，可运行 `python scripts/check.py --stage all` 验证文件边界、静态检查、前端构建和离线回归。

发行检查可以定位相关场景、编辑面板及故事图节点。语义召回保留数据库相似度排名，已有个人感知、来源删除及重要记忆回归；另用人工向量和快照测量过 100、1,000、5,000 条控制档案的上下文装配成本。这些受控检查不能替代自然长期游玩或真实 embedding 服务的规模验收。

## 尚未完成的验收

- 自然长对话、大规模召回与复杂推断尚未完整验收；固定自然累积运行曾在第六轮因无依据的历史细节或引用不匹配停止。生成引用或格式错误仍可能中断该轮回复；受控十二轮和失败恢复结果不保证其他剧情或输入同样成功。
- 公开源码 CI 配置检查 Python 3.12/3.13、锁定依赖、源码边界、前端构建及离线后端回归。实际结果绑定具体提交，可在仓库 GitHub Actions 查看；不能将本机结果或另一提交的通过等同当前提交的云 CI。
- 原生工具和游戏在开发机有分项运行证据，尚未完成干净 Windows 验收；长目录原生启动曾失败，长路径支持未完整验证。部分 Windows 安全策略会阻止未签名的原生后端；不要为运行测试关闭系统保护。源码 Studio 路径可用于继续测试，源码 alpha 发布不要求先取得代码签名。
- 已有官方语音样本和播放控制验证；同一音色的普通与“轻声、慢速、担心”两条样本经人工试听，达到测试版可用程度。其它音色、台词和整局语音表现仍需验证。

## 使用限制

审核格式恢复仅覆盖一个已复现的多余闭合括号；缺少结论不会推测补齐。相关解析与请求回归通过，历史失败稿重放保留原判断；这不证明整体响应提速或事实审核质量改善。有限真实对照仍发现部分历史事实漏判及合法表达误拒，长期对话质量尚未通过完整验收。

1. 尚未经过陌生创作者从空工程独立完成作品的外部验收。
2. 复杂多 NPC 场景可能出现重复表达、提前交还玩家或审核重试，等待时间可能较长，不承诺稳定的回复时延。
3. 复杂事实推断、时间归因、自然语言行动和长期记忆仍有局限。审核失败的候选不会作为正式世界事实提交。
4. 外部模型、embedding 和 TTS 可能因网络、地域或权限配置而不可用。默认采用 lexical 检索；启用向量检索前应单独验证 embedding 服务。语音失败可回退文字。
5. 源码仓库不附带 `Game.exe`、`GameBackend.exe`、PostgreSQL Windows 运行库或安装包。构建并分发独立 Windows 游戏需要自行准备这些组件，相关构建工具仍为实验性。
6. 作者可在场景演出段落的“按实际发言安排回应”中允许导演引用已发表的原话，默认关闭，保存工程后生效。角色仍只能使用本人实际听闻的内容，正式台词仍须审核。已有导演约束、段落约束或角色关注点可能使这种方式不适用；编辑器会提示原因，不要求作者删除约束。直接回应与导演段落复用实验默认关闭。
7. 更新前应备份工程和存档，新增故事字段不保证可被旧版本完整识别。
