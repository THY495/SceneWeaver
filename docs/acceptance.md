# alpha.2 验证范围与已知限制

本发布包是 Windows 优先、AI 驱动文字冒险开发工具的源码测试版本。提供角色扮演专用 Studio 入口、角色世界运行时和独立玩家前端，不包含办公助手入口、个人配置、密钥、玩家数据库、开发工作区的付费评测记录或 Windows 原生运行库。

## 本版内容

- 创作者可以编辑故事 DAG、场景背景与实体构图、角色经历/关系/知情范围、人物造型、固定开场和导演演出段落，以及物品与容器。
- 运行时区分世界事实、人物言论及各角色的实际观察；物品操作和剧情硬条件由确定性规则核验。
- 玩家使用自己的 LLM API Key。语音可选，须另有可用 TTS Key；默认不开启语音。
- 基于真实来源的任务快捷授权必须有明确作者许可，无许可的旧故事继续走自由任务语义审查。所有正式台词继续审核，世界操作权限保持。
- 附带纯离线回归测试和合成示例。scripts 下名称含 live 或 probe 的模型实验工具需要主动调用，可能消耗 API 费用；普通 scripts/check.py 不调用付费模型。

## 已验证与未验证

2026-10-08 的开发工作区重启检查走通了工程创建、场景修改、保存重开、真实 NPC 回答、手动分支转场到终端节点、服务重启后的进度和对白恢复。短句 TTS 生成并进入浏览器播放，媒体时长 2.13 秒。这是有限冒烟测试，不证明所有故事、AI 出口、多 NPC 交流或长期语义记忆均稳定可用，也不是 Windows EXE 或真人耳听验收。

本次修复了 API/Worker 产品不匹配导致的对话拒绝，以及窄窗口下工具栏被舞台遮挡的问题。向量索引曾出现阿里云 embedding 网络超时和 TLS 连接中断；文本试玩仍成功，但不能据此宣称语义索引可用。默认模板使用 lexical 检索，启用 embedding API 时请自行验证网络、地域和权限。不要关闭证书校验来处理连接异常。

本包的清单完整性和凭据模式检查可用 `python scripts/verify_release.py` 复核。快照自身的构建/测试结果由包旁验证收据记录；开发工作区此前的通过数字不替代发布快照的检查。

## 已知限制

1. 尚未经过陌生创作者从空工程独立完成作品的外部验收。
2. 复杂多 NPC 场景可能重复信息、提前交还或触发审核恢复；任务 completed 不自动等同于互动目标完成。没有稳定首条有效回复 4–6 秒的承诺。
3. 一般事实蕴含、时间归因、复杂行动解释与长对话记忆仍有改进空间。审核失败会停止或恢复任务，不能把失败输出当作已确认世界事实。
4. 网络和供应商错误可能导致向量索引或语音失败；语音失败可回退文字，但不能把错误视为正常语音体验。LLM 可用性是实际互动的前提。
5. 本源码包不附带 Game.exe、GameBackend.exe、PostgreSQL 原生运行库或可信签名安装包。Studio 可本地预览；构建并分发 Windows 独立游戏仍需自行准备相应运行库，最新版原生完整发行验收尚未完成。
6. 新版故事数据可能增加字段，建议保留原项目备份，不要把旧版本文件手工混入此快照。
7. 快捷授权的作者许可字段目前需通过故事 JSON/API 配置，尚无编辑器专用开关；旧故事不会自动获得该授权。它只减少部分任务授权工作，不取消台词审核或保证整轮提速。
