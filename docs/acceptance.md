# 验证范围与已知限制

Sceneweaver 当前为 Windows 优先的源码 alpha 版本，提供故事创作工具、角色世界运行时和独立玩家 Web 界面。

## 当前能力

- 编辑故事 DAG、场景背景与人物构图、角色经历与关系、知情范围、造型、固定开场和导演演出段落。
- 配置可操作物品和容器，由运行时核验物品操作与剧情硬条件。
- 区分世界事实、人物言论和各角色实际观察，保留个人记忆与执行诊断。
- 配置 AI 条件出口，在玩家交互满足条件后推进到新的场景。
- 玩家使用自己的 LLM API Key；语音可选，需要独立的 TTS API Key。

## 已验证的范围

两部合成故事已用于故事导入、编辑、构建和本地试玩。渡船故事验证过两条手动分支、汇合节点和两个结局；另用派生测试故事与真实模型验证过两个互斥 AI 出口。工程保存重开、服务重启后的对白与进度恢复、真实 NPC 回答和短句 TTS 播放均有有限验证。

上述结果不代表所有故事、AI 出口、多 NPC 交流或长对话记忆都稳定可用，也不是原生 Windows EXE 或整局语音验收。默认自动检查不调用付费模型；在安装开发依赖并启动测试数据库后，可运行 `python scripts/check.py --stage all` 验证文件边界、静态检查、前端构建和离线回归。

## 使用限制

1. 尚未经过陌生创作者从空工程独立完成作品的外部验收。
2. 复杂多 NPC 场景可能出现重复表达、提前交还玩家或审核重试，等待时间可能较长，不承诺稳定的回复时延。
3. 复杂事实推断、时间归因、自然语言行动和长期记忆仍有局限。审核失败的候选不会作为正式世界事实提交。
4. 外部模型、embedding 和 TTS 可能因网络、地域或权限配置而不可用。默认采用 lexical 检索；启用向量检索前应单独验证 embedding 服务。语音失败可回退文字。
5. 源码仓库不附带 `Game.exe`、`GameBackend.exe`、PostgreSQL Windows 运行库或安装包。构建并分发独立 Windows 游戏需要自行准备这些组件，相关构建工具仍为实验性。
6. 作者许可的来源回应任务只减少部分任务授权调用，正式台词仍须审核。该许可目前通过故事 JSON/API 配置，没有编辑器专用开关；已有故事不会自动获得许可。直接回应与导演段落复用实验默认关闭。
7. 更新前应备份工程和存档，新增故事字段不保证可被旧版本完整识别。
